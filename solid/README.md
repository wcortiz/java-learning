# SOLID Exercises

## Objetive

Practise object-oriented design by applying the SOLID principles to realistic business scenarios.

## Methodology

Each exercise is developed in different stages:

### Stage 1: Initial Requirements

Implement the first functional version of the system.

### Stage 2: System Evolution

Introduce new requirements to simulate real-world changes in a software project.

The goal is to assess whether the design can evolve without introducing unnecesarry complexity.

## Evaluation Criteria

During the implementation, the following aspects should be considered:

- Class responsabilities.
- Coupling.
- Extensibility.
- Separation of layers.
- Appropriate use of abstractions.
